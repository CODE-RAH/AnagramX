# 📝 معرفی پروژه

**ترکیب‌ساز حروف** یک ابزار گرافیکی سریع برای تولید تمام **جایگشت‌های ممکن** از یک مجموعه حروف است.  
کاربر حروف دلخواه و طول ترکیب را وارد می‌کند و برنامه در کمتر از یک ثانیه تمام ترکیب‌های منحصربه‌فرد را نمایش می‌دهد.

رابط کاربری با **PyQt6** ساخته شده و دارای تم تاریک بنفش و قابلیت کپی سریع به کلیپ‌بورد با یک کلیک است.

# ⌨️ نحوه استفاده

۱. حروف دلخواه را در کادر اول وارد کنید:

text
مثال: abcde

۲. تعداد حروف هر ترکیب را وارد کنید:

text
مثال: 3

۳. دکمه **⚡ تولید ترکیب‌ها** را بزنید.

۴. روی هر ترکیب کلیک کنید تا در کلیپ‌بورد کپی شود.
